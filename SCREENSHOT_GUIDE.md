# Safe screenshot checklist

1. Use fictional names, emails, projects, and tasks.
2. Remove any passwords, JWTs, browser developer tools, API keys, and database connection details.
3. Crop out browser bookmarks, desktop usernames, notifications, and private tabs.
4. Capture dashboard, project list, task board, and team management screens.
5. Save images in `screenshots/` and replace the pending lines in README.md with Markdown image links.
6. Do not publish a database export or real employee information.
